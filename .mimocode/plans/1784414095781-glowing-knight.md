# 命令系统重命名方案

## 目标

简化命令系统，消除与 AI 后端的命令冲突。

## 当前命令

| 命令 | 别名 | 功能 |
|------|------|------|
| `/switch <id>` | `/use`, `/backend` | 切换后端 |
| `/backends` | `/list`, `/ls` | 列出后端 |
| `/status` | — | 查看状态 |
| `/help` | — | 显示帮助 |

## 问题

1. `/status` 和 `/help` 是 AI 后端的常用命令，会冲突
2. `/use` 作为 `/switch` 的别名与用户习惯冲突（用户认为 `/use` 是"使用"而非"切换"）

## 新命令系统

| 命令 | 功能 |
|------|------|
| `/use` | 无参数：显示状态；有参数：切换后端 |
| `/backends` | 列出所有可用后端 |
| `/help` | 显示帮助 |

### `/use` 命令逻辑

```
/use                    → 显示当前状态（后端、在线数等）
/use openclaw            → 切换到 openclaw 后端
/use echo                → 切换到 echo 后端
```

### 移除的命令

- `/switch` — 被 `/use <id>` 替代
- `/backend` — 被 `/use <id>` 替代
- `/status` — 被 `/use`（无参数）替代
- `/list`、`/ls` — 被 `/backends` 替代

## 代码变更

### `pipeline.go` — CommandProcessor.Parse

```go
func (cp *CommandProcessor) Parse(text string) *CommandMatch {
    text = strings.TrimSpace(text)

    // /use — 无参数显示状态，有参数切换后端
    if text == "/use" {
        return &CommandMatch{Action: "show_status", Args: []string{}}
    }
    if match := matchPrefix(text, "/use "); match != "" {
        return &CommandMatch{Action: "switch_backend", Args: []string{match}}
    }

    // /backends — 列出后端
    if text == "/backends" {
        return &CommandMatch{Action: "list_backends"}
    }

    // /help — 显示帮助
    if text == "/help" {
        return &CommandMatch{Action: "show_help"}
    }

    return nil
}
```
