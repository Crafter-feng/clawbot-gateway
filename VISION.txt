# ClawBot Gateway — 版本统一管理

## 版本号规则

采用 **语义化版本** `MAJOR.MINOR.PATCH`：

- **MAJOR**: 不兼容的 API 变更
- **MINOR**: 向下兼容的功能新增
- **PATCH**: 向下兼容的问题修复

## 版本来源

VISION.txt 是 **唯一版本权威来源**。所有其他地方的版本号通过构建脚本自动注入。

## 当前版本

```
VERSION = 0.0.6
```

## 版本映射关系

| 位置 | 版本来源 | 说明 |
|------|---------|------|
| `VISION.txt` | 手动维护 | **唯一权威来源** |
| `internal/version/version.go` | `-ldflags` 注入 | 构建时由 `build-fpk.sh` 从 manifest 读取写入 |
| `fpk/manifest` | 构建脚本自动更新 | `sed -i "s/^version.*/version = ${VERSION}/"` |
| `web/package.json` | 手动同步 | 前端版本号，独立于构建版本 |
| `web/src-tauri/tauri.conf.json` | 手动同步 | Tauri 桌面端版本号，与 VISION.txt 一致 |
| Git tag | `v${VERSION}` | 发布时打 tag |

## 发布流程

```bash
# 1. 更新 VISION.txt 中的 VERSION
# 2. 同步 web/package.json 版本
# 3. 提交并打 tag: git tag v0.0.3 && git push origin v0.0.3
# 4. CI 自动构建 FPK 和 Docker 镜像
```
